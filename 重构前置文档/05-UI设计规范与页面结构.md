## 1. 设计原则

1. **工具感**：这是内部生产工具，追求「清晰、高效、可信」，不追求营销页的视觉冲击。
2. **一致性**：所有页面共用一套 tokens 与组件，交互反馈统一。
3. **内容优先**：编辑/预览区为主体，配置面板为辅助，信息密度适中。
4. **状态可视**：任务状态（待处理/处理中/已完成/失败）用统一色系 pill 表达，全局一致。
5. **可撤销/可确认**：删除、移除等破坏性操作必须二次确认。

### 5.2 视频水印 VideoWatermark（本期重点）

**布局**：左主区（视频预览 + 素材信息）+ 右侧配置面板（360px）。

#### 状态 A：未导入视频（空状态，v1.1 新增）

```
┌────────────────────────────────────────────────────────────┐
│ 视频水印                       [导入视频]  [保存到素材库]⛔    │
├────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────┐  │
│  │              ⬆  把视频拖到这里，或点击导入               │  │
│  │         MP4 / MOV / MKV / WEBM · 单文件 ≤ 2 GB        │  │
│  │         ————————————— 或 —————————————                │  │
│  │              从素材库选择（4 个视频）  ▾                │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

- 整块虚线区域即 Dropzone（高约 420px），键盘可达（`Enter` 触发选文件）。
- 右下角「从素材库选择」是次要入口，直接填满则跳过空状态。
- 右侧参数面板**隐藏**或置灰，避免用户先调参数再发现没视频。

#### 状态 B：已导入（编辑态）

```
┌────────────────────────────────────────────────────────────┐
│ 视频水印                 [保存方案] [保存到素材库]            │
├───────────────────────────────┬────────────────────────────┤
│  ┌─────────────────────────┐  │ 水印方案  [默认▾]  ⤓        │
│  │   <video> 原片           │  │ ─────────────────────────  │
│  │   + 绝对定位水印层        │  │ 文字水印  [✓启用]            │
│  │                         │  │   内容 [健衡学院        ]     │
│  │ [1920×1080 · MP4]  [▶]  │  │   位置 [右下 ▾](九宫格)       │
│  └─────────────────────────┘  │   字号[40] 颜色[■] 透明[0.8]  │
│  ▶ ────────●──────── 00:24/01:30│ ─────────────────────────  │
│                               │ Logo水印 [ 启用]             │
├───────────────────────────────┤   图片 [上传/选择素材]        │
│ 素材信息                       │   位置[左上] 宽[160] 透明[.85]│
│  格式 MP4·H.264   分辨率 1920×1080│ ─────────────────────────  │
│  时长 01:30       大小 2.4 MB  │ 通用 · 编码参数  CRF20·medium▾│
│  来源 本地文件·未入库  ⚠       │                            │
│  [换一个视频]                  │ ✓ 水印配置校验通过，可保存      │
└───────────────────────────────┴────────────────────────────┘
```

**关键点**：

| 元素 | 规范 |
|---|---|
| 预览 | 真实 `<video>`（本地 `objectURL` 或素材库 `stream_url`），`muted` 默认静音，播放/暂停/进度条自绘 |
| 水印层 | 覆盖在 `<video>` 上的绝对定位层，按 1920 基准等比缩放字号与边距；**只做效果示意**，左下角标注「预览为效果示意」 |
| 画面裁切 | `<video>` 用 `object-fit: cover` 铺满舞台，**不要用 contain**：contain 会留黑边，水印锚点会落到黑边而不是画面上 |
| 来源徽标 | 「素材库」= 绿色 pill；「本地文件 · 未入库」= 琥珀色 pill，mouseover 提示「刷新页面后失效」 |
| 换一个视频 | 素材信息卡右下文字按钮，重新打开文件选择，同时保留当前水印参数 |
| 底部校验条 | 常驻（sticky bottom），通过时绿字「✓ 水印配置校验通过，可保存」；不通过时红字给出第一条原因 |

#### 状态 C：已提交（等待态）

点「保存到素材库」后：**立即跳转任务中心**并高亮该任务，视频页再次进入时按钮变为「查看任务进度 →」。

```
任务中心
┌────────────────────────────────────────────────────────────┐
│ 产品宣传片 · 水印   视频水印   [● 处理中 42%] 张嘉怡  刚刚   │
│                              └──────────────             │
│                                ███████░░░░░               │
└────────────────────────────────────────────────────────────┘
        完成后 → [已完成] + 详情里「下载成品」「在素材库查看」
```

**交互流程**：

1. **导入**：点击「导入视频」或拖拽 → 校验扩展名白名单与 2 GB 上限 → `objectURL` 喂 `<video>` → `loadedmetadata` 读出时长/宽高 → 进入编辑态。
2. **配置**：右侧改参数，左侧 DOM 实时跟随；「抽帧预览」调 `POST /watermark/preview` 得到真实单帧。
3. **保存方案**：只写 `watermark_configs`，Toast「水印方案已保存」，**不产生素材**。
4. **保存到素材库**：
   - 按钮 loading（文案变「上传中…」）；
   - 依次 `POST /assets/upload` → `POST /tasks(save_to_assets=true)`；
   - 成功后 Toast「已提交，正在渲染并写入素材库」+ `navigate('tasks', taskId)`；
   - 失败（网络/校验）留在本页，Toast 展示错误，按钮恢复。
5. **取用**：任务详情「下载成品」直接下载；素材库「视频」分类可见来源徽标「任务产出」。

**校验**（保存到素材库前置条件）：

- [ ] 已导入视频且元信息读取成功；
- [ ] 文字与 Logo 至少启用一项；
- [ ] 启用 Logo 时已选择图片且宽度 ≥ 32px。

任一不满足：主按钮 `disabled` + 底部校验条给出原因。

**按钮语义对照（避免误用）**：

| 按钮 | 视觉 | 结果 | 是否跳转 |
|---|---|---|---|
| 保存方案 | ghost | 新增一条水印模板 | 否，仅 Toast |
| 保存到素材库 | primary | 建任务 → 渲染 → 成品入库 | 是，跳任务中心 |

### 5.3 文章编写 ArticleEditor

**布局**：左侧「需求输入」，右侧「生成结果」（可切换为「仅编辑」视图）。

```
┌────────────────────────────────────────────────────────────┐
│ 文章编写            [保存草稿] [导出▾] [生成文章]              │
├──────────────────────────────┬─────────────────────────────┤
│ 需求输入                      │ 生成结果（分节展示，可编辑）        │
│  平台   [小红书 ▾]             │  【标题】可编辑                 │
│  内容类型 [种草带货 ▾]          │  【正文】可编辑                 │
│  受众档位 [通俗 ▾]             │  【标签/话题】可编辑             │
│  主题/产品 [____________]     │  【合规自检】只读               │
│  核心卖点 [____________]     │  【搜索覆盖自检】表格             │
│  字数     [____________]     │                              │
│  补充要求 [textarea_____]     │  写作统计：字数 / 预计阅读 / 覆盖   │
│  参考图 [上传 1~3 张]          │                              │
│  搜索关键词 [气压靴] 词库策略[▾] │                              │
└──────────────────────────────┴─────────────────────────────┘
```

**交互**：
- 「生成文章」→ `POST /tasks`（type=article）→ 跳转任务中心或轮询等待 → 完成后回填结果。
- 结果区正文可编辑（contentEditable 或富文本），改完「保存草稿」/「导出 Markdown/纯文本」。
- 带关键词时，右侧显示「词库策略」选项；可选「手动补采」触发 `POST /lexicon/{keyword}/ensure`。

**保存草稿（v1.1）**：

```
                    ┌─────────────────────────────────┐
[保存草稿] ────────▶ │ 按钮 loading「保存中…」            │
                    │      ↓ 成功                      │
                    │ Toast：草稿已保存到素材库（1.6s）    │
                    │      ↓                          │
                    │ 结果区头部 meta 变为：             │
                    │ 「保存于 刚刚 · 已存入素材库 ↗」     │
                    └─────────────────────────────────┘
```

| 场景 | 行为 |
|---|---|
| 已有生成结果 | 保存「需求 + 标题 + 正文 + 标签 + 自检」为 Markdown 素材，`folder=草稿/文章` |
| 尚未生成 | 仍可保存，落「需求草稿」，Toast 文案改为「需求已保存到素材库」 |
| 重复保存 | 命中同一条草稿（`PUT`），Toast「草稿已更新」，素材库不新增条目 |
| 保存失败 | Toast 报错，按钮恢复，编辑器内容不丢 |

- 结果区头部的 `保存于 xx` 文案由服务端 `updated_at` 驱动，不再用前端假时间。
- 「已存入素材库 ↗」可点击，`navigate('assets', { source: 'draft' })` 直接跳到素材库并筛出草稿。
- 保存按钮在内容为空（既无正文也无主题）时禁用并提示。

**状态列与进度（v1.1）**：

```
[● 处理中]              状态 pill
 ███████░░░░░  42%      2px 高进度条，宽 72px，主色填充，仅在 processing 时出现
```

- 进度条与 pill 上下排布（列宽 100px），数字用等宽字体。
- `done` 后进度条消失，视频任务额外显示「已入库」小标签（绿色 outline）。
- 进度来自 SSE 的 `progress`；断流时用 3s 轮询 `GET /tasks/{id}` 兜底。

**任务详情（抽屉或独立页）**：展示完整结果 + 失败原因 + 重试/取消/删除。视频任务在 `done` 时提供两个动作：

| 动作 | 行为 |
|---|---|
| 下载成品 | 走 `result.download_url`（即成品素材的下载接口） |
| 在素材库查看 | `navigate('assets', { source: 'task', assetId })`，高亮该素材 |

删除任务时若已产出素材，删除确认框需写明「已产出的成品会保留在素材库」。

### 5.6 素材库 AssetLibrary

沿用 Demo 结构：搜索 + 类型 chip + 网格卡片（缩略图/名称/格式/大小/时间）+ 存储用量条。

**来源徽标（v1.1）**：

```
┌──────────────────────────┐
│ [MP4]              01:30 │  ← 左上：扩展名    右下：时长
│      缩略图          (○) │  ← 右上：勾选圆点
│ ★草稿                    │  ← 左下：来源徽标
├──────────────────────────┤
│ 气压靴种草文 · 草稿         │
│ MD · 4 KB · 刚刚          │
└──────────────────────────┘
```

> 徽标固定在**左下角**：右上角是勾选圆点、右下角是时长，三者不能互相遮挡。徽标只做「附加来源」的提示，默认来源（上传）不打扰。

| source | 徽标文案 | 配色 |
|---|---|---|
| `upload` | 不上徽标 | —（默认情况不打扰） |
| `task` | 任务产出 | 实色底 `rgba(20,158,140,.94)` + 白字 |
| `draft` | 草稿 | 实色底 `rgba(206,138,44,.94)` + 白字 |

> 缩略图有深（视频）有浅（文档），淡色底 + 彩色字在浅色缩略图上会消失，所以徽标用**实色底 + 白字**，10px / 600。视频页「素材信息」里的来源标签仍在白底上，可以继续用淡底彩字。

**来源筛选**：工具栏类型 chip 右侧加一组轻量筛选 `全部 | 上传 | 任务产出 | 草稿`（Segmented 小尺寸），与类型 chip 是**与**关系。点某个来源时，若当前分类下没有该来源的素材，**自动跳到第一个有内容的分类**，避免出现「筛选完是空列表」；空列表文案也要说明是「当前分类下没有该来源」，而不是笼统的「没有匹配素材」。

**下载行为**：

| 类型 | 下载 |
|---|---|
| 视频/图片 | 原文件流 |
| 文档（含草稿 .md） | `GET /assets/{id}/download`，文件名 `name.ext` |
| 任务产出 | 同视频，`Content-Disposition` 用成品名 |

**其他**：卡片来源为真实素材（`GET /assets`），缩略图为后端生成；上传走 Dropzone（支持分块）。`task` 类素材在悬浮操作里多一个「查看来源任务」。

| 动作 | 接口 | 结果 |
|---|---|---|
| 保存默认 | `PUT /system/watermark-default` | 全站初值更新，Toast「默认水印已更新，新开页面生效」 |
| 另存为方案 | `POST /watermark/configs` | 弹出命名输入，确认后在方案下拉可见 |

**通用规范**：
- 敏感字段（api_key）脱敏显示 + 眼睛图标切换明文。
- 任何分区改动后顶部「保存更改」才激活；未保存切分区不丢失草稿（draft 状态保留在内存）。
- 保存成功后热加载生效，无需重启。

## 6. 交互与反馈规范

| 场景 | 反馈 |
|---|---|
| 表单校验失败 | 字段下方红色 11px 错误文案 |
| 提交成功 | 底部 Toast（「任务已提交」）+ 跳转/按钮态变化 |
| **保存到素材库** | 按钮 loading「上传中…」→ Toast「已提交，正在渲染并写入素材库」→ 跳任务中心并高亮该任务 |
| **保存草稿** | 按钮 loading「保存中…」→ Toast「草稿已保存到素材库」→ 结果区 meta 变「保存于 刚刚 · 已存入素材库 ↗」 |
| 处理中 | 状态 pill 蓝底「处理中」+ 下方 2px 进度条 + 百分比 |
| 处理失败 | 状态 pill 红底「失败」+ 详情页展示失败原因 |
| **产物入库** | 任务 `done` 后状态列出现「已入库」标签；素材库对应卡片带「任务产出」徽标 |
| 删除/移除 | Modal 二次确认（Confirm）；删除任务时提示「已产出成品会保留」 |
| 上传中 | 进度条（单文件百分比 / 分块进度） |
| 无权限 | 路由重定向 + Toast「无权访问该页面」 |
| 空状态 | Empty 组件 + 引导文案 |

## 7. 响应式

- 桌面优先（≥1180px 完整布局）。
- 1180~980px：模块卡片单列、统计两列、右侧面板收窄。
- <980px：侧边栏折叠为图标栏（76px），编辑器左右布局改上下堆叠。
- 目标场景为桌面端，移动端仅保证基本可用（非重点）。

---

## 8. 可访问性与细节

- 图标按钮必须有 `aria-label`。
- 状态不只靠颜色区分，同时用文字（如「处理中」）。
- 视频进度条支持键盘操作（role=slider + 方向键）。
- 焦点态可见（主色描边）。
- 数字统一等宽字体（`tabular-nums`）。
